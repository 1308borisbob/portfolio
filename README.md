# Пример расширения для 1С ЗУП (зарплатная структура)

Хранит данные о средних величинах зарплаты организации в разрезе нескольких показателей. Отчет показывает основные кадровые данные из основной конфигурации ЗУП и соответствующие значения средних зарплат для сотрудников. Возможна выгрузка данных по сотрудникам, включая зарплатную структуру, во внешнюю систему, в которой эти данные будут использоваться.
