# Пример расширения для 1С (зарплатная структура)

Основная конфигурация - доработанная 1С ЗУП. Расширение предназначено для ввода, хранения и выгрузки во внешнюю систему данных о средних(медианных) величинах зарплаты в организации в разрезе нескольких показателей.

# Отчет с использованием данных табеля учета рабочего времени

Конфигурация - доработанная 1С ЗУП. Отчет сравнивает отработанные часы из табеля учета рабочего времени с оплаченными часами, в случае расхождения выводится дельта. Используется БСП варианты отчетов.

# Отчет история занятости позиций штатного расписания

Конфигурация - доработанная 1С ЗУП. Отчет выводит текущий статус позиции, сотрудников занимающих позицию, дату начала и окончания для каждого сотрудника и другие данные из штатного расписания.
